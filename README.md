# Case Log：醫美病例學習紀錄

為醫美醫師設計、以手機操作為主的個人病例學習系統，用來追蹤值得學習的病例。

- **本機優先**：所有病例與照片只存在手機瀏覽器（IndexedDB），不會上傳到任何伺服器
- **可離線、可加入主畫面**（PWA），用起來就像一般 App
- 不需安裝套件，也沒有建置流程：只有靜態檔案（`index.html`、`app.js`、`app.css`、`sw.js`）

## 功能
- 30 秒快速記錄：只有「標題」必填；類別、部位、主訴、併發症、標籤都用點選
- 照片：拍照或從相簿選、標記術前／術中／術後；會自動壓縮並移除 GPS 等 EXIF
- 前後比較：滑桿與並排兩種模式，可任選兩張照片
- 回診追蹤：時間軸會顯示「術後第 N 天」，並提醒已到期的回診
- 💡 學習重點（Pearl）彙整，加上**隨機複習**（先看照片想一想，再看自己的心得）
- 搜尋、篩選（類別／追蹤中／收藏／併發症）、統計
- 完整備份與還原（JSON，含照片）、匯出 CSV、複製病例摘要

## 安裝到 iPhone
1. 用 GitHub Pages 部署這個 repo（Settings → Pages → Deploy from a branch）
2. 用 **Safari** 開啟網址 → 分享 →「加入主畫面」

> 資料存在「這支手機的這個瀏覽器」。刪除 App 或清除 Safari 網站資料，病例會一起被刪除，請定期在「設定」裡備份。
